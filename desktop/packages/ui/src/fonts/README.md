# Fonts

Inter 4.1 by The Inter Project Authors (https://github.com/rsms/inter), the
variable web fonts from the v4.1 release (`web/InterVariable.woff2` and
`web/InterVariable-Italic.woff2`), unchanged.

- Licence: SIL Open Font License 1.1, in `OFL.txt` next to this file.
- The variable font carries the optical-size axis (`opsz` 14 to 32). Its 32
  end is the Inter Display cut, which page titles use through the
  `font-display` class in `../app.css`, so one file serves both Inter and
  Inter Display.
- Bundled with the app; nothing is fetched from the internet at runtime.
